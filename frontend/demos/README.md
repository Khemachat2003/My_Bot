# frontend/demos — ไฟล์ demo กราฟ (standalone)

ไฟล์ HTML เหล่านี้เป็น **demo แยกต่างหาก** จาก dashboard หลัก (frontend/index.html)
โหลดไลบรารีจาก CDN (unpkg.com) โดยตรง จึงเปิดจากตำแหน่งไหนก็ได้ (double-click เปิดในเบราว์เซอร์)

| ไฟล์ | สาธิต |
|---|---|
| equity-curve-demo.html | Equity Curve แบบ area series |
| multi-pane-chart-demo.html | แยก pane ราคา/volume/indicator (sync zoom) |
| tradingview-style-chart-demo.html | กราฟแบบ TradingView (candle + markers + crosshair legend) |
| trading-terminal-style-reference.html | ธีม/เลย์เอาต์อ้างอิงสไตล์ trading terminal |

Brief สำหรับมอบหมายงาน redesign อยู่ที่ `../design/`
